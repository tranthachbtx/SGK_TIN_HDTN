### 1. Kiểu dữ liệu danh sách (List)
    List là kiểu dữ liệu danh sách (dãy, mảng) trong Python. Tạo list bằng lệnh gán với các phần tử trong cặp dấu ngoặc [].
    
    #### a) Khởi tạo danh sách
    **Cú pháp:**
    ```python
    <tên_danh_sách> = [<giá trị 1>, <giá trị 2>, ..., <giá trị n>]
    ```
    
    **Đặc điểm:**
    - Các phần tử của danh sách có thể có các kiểu dữ liệu khác nhau
    - Các giá trị cách nhau bởi dấu phẩy
    - Có thể tạo danh sách rỗng
    
    **Ví dụ:**
    ```python
    A = [1, 2, 3, 4, 5]
    B = [1.5, 2, "Python", "List", 0]
    a = []  # Danh sách rỗng
    ```
    
    #### b) Truy cập phần tử
    Truy cập hoặc thay đổi giá trị của từng phần tử thông qua chỉ số:
    ```python
    <tên_danh_sách>[<chỉ số>]
    ```
    
    **Quy tắc quan trọng:**
    - Chỉ số của danh sách bắt đầu từ 0 đến len() - 1
    - len() là lệnh tính độ dài danh sách
    
    **Ví dụ:**
    ```python
    A = [1, 2, 3, 4, 5]
    A[0]    # 1
    B = [1.5, 2, "Python", "List", 0]
    B[2]    # 'Python'
    ```

    ### 2. Duyệt các phần tử của danh sách

    #### Hoạt động 2: Dùng lệnh for để duyệt danh sách

    Quan sát các lệnh sau để biết cách dùng lệnh for duyệt lần lượt các phần tử của một danh sách.

    **Ví dụ 1: Duyệt và in ra từng phần tử của danh sách**
    ```python
    A = [1,2,3,4,5]
    for i in range(len(A)):  # Biến i chạy trên vùng chỉ số từ 0 đến len(A) - 1
        print(A[i], end = " ")
    # Kết quả: 1 2 3 4 5
    ```

    **Ví dụ 2: Duyệt và in một phần của danh sách**
    ```python
    A = [3, 2, 1, 5, 6, 10, 7, 12, 18]
    for i in range(2,5):
        print(A[i], end = " ")
    # Kết quả: 1 5 6
    ```

    **Giải thích:**
    - Hai ví dụ trên cho thấy dùng lệnh for kết hợp với lệnh range() để duyệt từng phần tử của danh sách
    - Có thể duyệt lần lượt các phần tử của danh sách bằng lệnh for kết hợp với vùng giá trị của lệnh range()

    **Bài tập thực hành:**

    **Bài tập 1:** Giải thích các lệnh ở mỗi câu sau thực hiện công việc gì?
    ```python
    # a)
    S = 0
    for i in range(len(A)):
        if A[i] > 0:
            S = S + A[i]
    print(S)
    # => Tính tổng các phần tử dương trong danh sách A

    # b)
    C = 0
    for i in range(len(A)):
        if A[i] > 0:
            C = C + 1
    print(C)
    # => Đếm số lượng phần tử dương trong danh sách A
    ```

    **Bài tập 2:** Cho dãy các số nguyên A, viết chương trình in ra các số chẵn của A.

    **Gợi ý:**
    ```python
    for i in range(len(A)):
        if A[i] % 2 == 0:
            print(A[i], end = " ")
    ```

    ### 3. Thêm phần tử vào danh sách

    Python có những lệnh đặc biệt để thêm phần tử vào một danh sách. Các lệnh này được thiết kế riêng cho kiểu dữ liệu danh sách và còn được gọi là phương thức (method) của danh sách.

    #### Hoạt động 3: Tìm hiểu lệnh thêm phần tử cho danh sách

    Quan sát các lệnh sau đây để biết cách thêm phần tử vào một danh sách bằng phương thức append().

    **Ví dụ: Thêm phần tử vào cuối danh sách**
    ```python
    A = [1,2]
    A.append(10)
    print(A)  # [1, 2, 10]
    ```

    **Chú ý cách dùng phương thức append():**
    - Gõ tên biến danh sách, dấu ".", sau đó gõ append
    - Ví dụ: `dsLop.append(name)`

    **Tổng kết về phương thức:**
    - Python có một số lệnh dành riêng (phương thức) cho dữ liệu kiểu danh sách
    - Cú pháp các lệnh đó như sau: `tên_danh_sách.tên_phương_thức()`
    - Lệnh thêm phần tử vào cuối danh sách là `.append()`

    **Câu hỏi suy ngẫm:**
    - Sau khi thêm một phần tử vào danh sách A bằng lệnh append() thì độ dài danh sách A thay đổi như thế nào?
    - Danh sách A sẽ như thế nào sau các lệnh sau?
    ```python
    A = [2,4,10,1,0]
    A.append(100)
    del A[1]
    # => A = [2, 100, 10, 1, 0]
    ```

    ### 4. Thay đổi và xóa phần tử
    
    #### a) Thay đổi giá trị phần tử
    Sử dụng lệnh gán để thay đổi giá trị từng phần tử:
    ```python
    A = [1, 2, 3, 4, 5]
    A[1] = "One"
    print(A)    # [1, 'One', 3, 4, 5]
    ```
    
    #### b) Xóa phần tử
    Sử dụng lệnh del để xóa một phần tử của danh sách:
    ```python
    A = [1, 'One', 3, 4, 5]
    del A[4]
    print(A)    # [1, 'One', 3, 4]
    ```
    
    #### c) Các phép toán với danh sách
    - **len(A)**: Tính độ dài của danh sách
    - **Phép ghép (+)**: Ghép hai danh sách
    
    **Ví dụ:**
    ```python
    a = []  # Danh sách rỗng có độ dài bằng 0
    len(a)  # 0
    
    [1, 2] + [3, 4, 5, 6]  # [1, 2, 3, 4, 5, 6]
    ```

    **Chương trình mẫu:**
    ```python
    A = []
    T = 0
    n = int(input("Nhập số tự nhiên n: "))

        A.append(num)
        T = T + num
    ```

    ```python
    max_val = A[0]

            max_index = i
    print("Phần tử lớn nhất:", max_val, "tại chỉ số", max_index)
    ```
