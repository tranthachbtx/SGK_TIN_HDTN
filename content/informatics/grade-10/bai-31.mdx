    <div className="space-y-3">
### Bài tập thực hành
    
    #### Bài tập 1: Nhận biết lỗi ngoại lệ
    Các lệnh sau có sinh lỗi chương trình không? Nếu có thì mã lỗi là gì?
    
    a) 
    ```python
    A = [1, 3, 5, 10, 0]
    for k in range(1, len(A) + 1):
        print(A[k])
    ```
    
    **Phân tích:**
    - Danh sách A có 5 phần tử (chỉ số 0-4)
    - Vòng lặp chạy từ 1 đến 5 (len(A) + 1 = 6)
    - Khi k = 5, A[5] sẽ gây ra **IndexError**
    
    b) 
    ```python
    s1, s2 = "101010", 1010101
    s = s1 + s2
    ```
    
    **Phân tích:**
    - Không có lỗi, Python tự động chuyển số 1010101 thành xâu khi nối với xâu
    
    #### Bài tập 2: Phân tích lỗi có thể xảy ra
    Để tính giá trị trung bình của một danh sách số A, người lập trình đã dùng lệnh sau để tính:
    ```python
    gttb = sum(A)/len(A)
    ```
    
    Lệnh này có thể sinh lỗi ngoại lệ không? Nếu có thì là những lỗi gì?
    
    **Phân tích các lỗi có thể xảy ra:**
    
    1. **ZeroDivisionError:**
    - Khi danh sách A rỗng (len(A) = 0)
    - sum(A) = 0, len(A) = 0 → chia cho 0
    
    2. **TypeError:**
    - Khi danh sách A chứa các phần tử không phải số
    - Ví dụ: A = [1, 2, "abc", 3]
    - sum(A) không thể thực hiện được
    
    3. **NameError:**
    - Khi biến A chưa được định nghĩa
    
    #### Bài tập 3: Xác định mã lỗi
    Hãy nêu mã lỗi ngoại lệ của mỗi lệnh sau nếu xảy ra lỗi:
    
    a) `A[1.5]` → **TypeError** (chỉ số phải là số nguyên)
    
    b) `int("abc")` → **ValueError** (không thể chuyển "abc" thành số nguyên)
    
    c) `"10"*3.5` → **TypeError** (không thể nhân xâu với số thực)
    
    d) `12 + x(10)` → **TypeError** (x không phải là hàm hoặc không được định nghĩa)
    
    #### Thực hành tại máy:
    Viết chương trình nhập các số nguyên m, n từ bàn phím, cách nhau bởi dấu cách. Chương trình đưa ra tổng, hiệu, thương của hai số đã nhập.
    
    **Chương trình mẫu:**
    ```python
    s = input("Nhập hai số m, n cách nhau bởi dấu cách: ")
    sline = s.split()
    m, n = int(sline[0]), int(sline[1])
    print("Tổng, hiệu, thương 2 số đã nhập là:", m+n, m-n, m/n)
    ```
    
    **Các khả năng sinh lỗi của chương trình:**
    - Các số m, n khi nhập vào không là số nguyên → **ValueError**
    - Giữa hai số m, n không có dấu cách → **IndexError**
    - Số n nhập vào là số 0 → **ZeroDivisionError**

### Bài tập vận dụng
    
    #### Bài tập 1: Chương trình tìm ước số với kiểm thử
    Giả sử em được yêu cầu viết một chương trình nhập số tự nhiên n từ bàn phím, kết quả đưa ra là danh sách các ước số thực sự của n, tính cả 1 và không tính n. Hãy viết chương trình và kiểm tra các khả năng sinh lỗi khi thực hiện chương trình.
    
    **Chương trình mẫu:**
    ```python
    def tim_uoc_so(n):
        uoc_so = []
        for i in range(1, n):
            if n % i == 0:
                uoc_so.append(i)
        return uoc_so
    
    try:
        n = int(input("Nhập số tự nhiên n: "))
        if n <= 1:
            print("Số phải lớn hơn 1 để có ước số thực sự!")
        else:
            ds_uoc = tim_uoc_so(n)
            print(f"Các ước số thực sự của {n}: {ds_uoc}")
    except ValueError:
        print("Vui lòng nhập số nguyên!")
    except Exception as e:
        print(f"Đã xảy ra lỗi: {e}")
    ```
    
    **Kiểm thử các trường hợp:**
    - **Dữ liệu biên:** n = 1, n = 2
    - **Dữ liệu bất thường:** n = 0, n = -5, nhập "abc"
    - **Dữ liệu thông thường:** n = 10, n = 100
    
    #### Bài tập 2: Tạo chương trình sinh lỗi NameError
    Em hãy viết một chương trình nhỏ để khi chạy sẽ sinh mã lỗi NameError.
    
    **Chương trình mẫu:**
    ```python
    # Chương trình sinh lỗi NameError
    print(x)  # x chưa được định nghĩa
    
    # Hoặc:
    def tinh_tong(a, b):
        return a + c  # c chưa được định nghĩa
    
    tinh_tong(1, 2)
    ```
    
    #### Bài tập 3: Chương trình nhập danh sách số với kiểm thử
    Viết chương trình nhập số tự nhiên n và nhập lần lượt n số nguyên đưa vào danh sách số A. Sau khi nhập xong in danh sách A ra màn hình.
    
    **Chương trình mẫu với xử lý lỗi:**
    ```python
    def nhap_danh_sach():
        try:
            n = int(input("Nhập số tự nhiên n: "))
            if n <= 0:
                print("Số phải nguyên dương!")
                return []
            
            A = []
            for k in range(n):
                while True:
                    try:
                        num = int(input(f"Nhập số thứ {k+1}: "))
                        A.append(num)
                        break
                    except ValueError:
                        print("Vui lòng nhập số nguyên!")
            
            return A
        except ValueError:
            print("Vui lòng nhập số nguyên cho n!")
            return []
        except Exception as e:
            print(f"Đã xảy ra lỗi: {e}")
            return []
    
    # Chương trình chính
    danh_sach = nhap_danh_sach()
    if danh_sach:
        print("Dãy đã nhập:", danh_sach)
    
    # In thông số trung gian để kiểm tra
    print(f"Số phần tử: {len(danh_sach)}")
    print(f"Tổng các phần tử: {sum(danh_sach)}")
    ```
    
    #### Thảo luận:
    - Tại sao cần kiểm thử chương trình với nhiều bộ dữ liệu khác nhau?
    - Lợi ích của việc in thông số trung gian khi gỡ lỗi là gì?
    - Khi nào nên dùng try...except và khi nào nên dùng if...else để kiểm tra lỗi?
