    <div className="space-y-4">
### 1. Các lệnh vào ra đơn giản
    Trong Bài 1 chúng ta đã biết quá trình xử lí thông tin trong máy tính thực chất cũng là xử lí dữ liệu. Do vậy, trong các ngôn ngữ lập trình bậc cao cần có các câu lệnh tương ứng để nhập, xuất dữ liệu. Trong Python, lệnh print() có chức năng đưa dữ liệu ra, còn lệnh input() đưa dữ liệu vào.
    
    #### a) Lệnh input()
    **Chức năng:** Nhập dữ liệu từ thiết bị vào chuẩn, thường là bản phím.
    
    **Cú pháp:** `tên_biến = input("Thông báo")`
    
    **Đặc điểm quan trọng:** Nội dung nhập có thể nhập số, biểu thức hay xâu và cho kết quả là một **xâu kí tự**.
    
    **Ví dụ:**
    ```python
    input("Nhập một số: ")
    Nhập một số: 12
    '12'
    ```
    
    **Ví dụ nhập xâu ký tự:**
    ```python
    name = input("Nhập họ tên em: ")
    print("Xin chào ", name)
    ```
    
    #### b) Lệnh print()
    **Chức năng:** Đưa dữ liệu ra thiết bị ra chuẩn, thường là màn hình.
    
    **Đặc điểm:** Thông tin cần đưa ra có thể bao gồm một hay nhiều dữ liệu với kiểu khác nhau, cho phép cả biểu thức tính toán.

    ### 2. Chuyển đổi kiểu dữ liệu cơ bản của Python
    Chúng ta đã biết một số kiểu dữ liệu cơ bản như số nguyên, số thực và xâu kí tự. Trong Python có cách để nhận biết kiểu dữ liệu của biến.
    
    #### a) Nhận biết kiểu dữ liệu với lệnh type()
    **Ví dụ:**
    ```python
    n, x, s = 10, 1.8, "One"
    # Gán n = 10, x = 1.8, s = "One" đồng thời
    
    n
    10
    type(n)
    <class 'int'>    # Biến n thuộc kiểu int - số nguyên
    
    type(x)
    <class 'float'>  # Biến x thuộc kiểu float - số thực
    
    type(s)
    <class 'str'>    # Biến s thuộc kiểu str - xâu kí tự
    ```
    
    **Kiểu dữ liệu logic (bool):** Chỉ có hai giá trị là True (đúng) và False (sai).
    ```python
    3 > 2
    True
    5 < 0
    False
    b = 10 > 3
    type(b)
    <class 'bool'>
    ```
    
    **Kết nối tri thức:**
    - Tên kiểu dữ liệu logic là bool.
    - Một số kiểu dữ liệu cơ bản của Python bao gồm: int (số nguyên), float (số thực), str (xâu kí tự), bool (logic).
    - Lệnh type() dùng để nhận biết kiểu dữ liệu của biến trong Python.

    #### b) Chuyển đổi giữa các kiểu dữ liệu
    **Lệnh int():** Chuyển đổi số thực hoặc xâu chứa số nguyên thành số nguyên.
    
    **Lệnh float():** Dùng để chuyển đổi số nguyên và xâu kí tự thành số thực.
    
    **Lệnh str():** Dùng để chuyển đổi các kiểu dữ liệu khác thành xâu kí tự.
    
    **Lưu ý quan trọng:** Các lệnh int(), float() chỉ có thể chuyển đổi các xâu ghi giá trị số trực tiếp, không chuyển đổi xâu có công thức.
    
    **Ví dụ lỗi:**
    ```python
    int('12+45')
    ValueError: invalid literal for int() with base 10: '12+45'
    ```
    
    #### c) Nhập dữ liệu kiểu số nguyên hoặc số thực từ bản phím
    Dữ liệu nhập từ bản phím bằng lệnh input() luôn là xâu kí tự nên muốn nhập dữ liệu đầu vào là số nguyên hay số thực thì phải chuyển đổi kiểu.
    
    **Cú pháp nhập số nguyên:**
    ```python
    n = int(input("Nhập số nguyên n: "))
    ```
    
    **Cú pháp nhập số thực:**
    ```python
    x = float(input("Nhập số thực x: "))
    ```
